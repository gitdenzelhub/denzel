# Site content

Everything on the site is edited from this file. Save it, refresh the browser,
and the page rebuilds itself. You never need to touch the HTML.

Rules:
  * `key: value` sets a single field.
  * `- a | b | c` adds a row to a list. The columns are described above each list.
  * Any other line (like this one) is ignored, so notes are safe to leave around.

Voice: first person, always. This is Denzel's site, so it is written the way he
would say it out loud. No em dashes, no marketing filler.

opens the five colour swatches, so you can try each scheme on the real
page. Set it to `off` once you have picked, and put your choice in
`palette` above.
