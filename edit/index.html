One-time setup. It gives this browser a key that lets it publish to the site. The key stays on this device only.

  1. Sign in to GitHub as gitdenzelhub, then tap the button below.
  2. Under Repository access, choose Only select repositories and pick denzel.
  3. Under Permissions, set Contents to Read and write.
  4. Tap Generate token, copy it, and paste it here.
